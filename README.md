# Hangman Game – Python

## Project Description
This is a simple text-based Hangman Game developed using Python as part of my CodeAlpha Python Programming Internship.

The player needs to guess a hidden word one letter at a time. The game provides a maximum of six incorrect attempts to guess the word correctly.

## Features
- Random word selection from a predefined word list.
- One-letter-at-a-time guessing.
- Maximum of six incorrect attempts.
- Input validation.
- Prevents repeated guesses.
- Displays the player's progress.
- Shows win or lose results.

## Technologies Used
- Python 3
- Random module

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder in your terminal.
4. Run the following command:

```bash
python hangman.py
```
